These skill directories are copied **verbatim** (content and file modes unchanged) from
[obra/superpowers](https://github.com/obra/superpowers) tag **v6.4.1**,
commit `b92c4fa87ea1252077a7f7d3bf420e52325dd25e`, fetched 2026-09-19:

| Directory | Upstream path |
|---|---|
| `test-driven-development/` | `skills/test-driven-development/` |
| `verification-before-completion/` | `skills/verification-before-completion/` |

Don't edit these files. To update, fetch a newer tag, replace the directories wholesale, and change the SHA above.

compete with this repo's project-interview → write-spec → plan-tasks workflow.

`superpowers:verification-before-completion`; in this repo those are the unprefixed skills above.
