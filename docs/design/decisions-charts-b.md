# Decisions: the new chart types (lane CHARTS-B)

Later decisions for P2.27 (F49–F55, design 23), in the table of [`decisions-2026-10-08.md`](./decisions-2026-10-08.md)'s "Later decisions", kept here so the parallel lanes don't conflict there.

| ID | Question | Decision | Why | Departs |
|---|---|---|---|---|
| T990-1 where Distribution is stored (AC-591, AC-306) | Under which option do Points and Violin live? | **`options.distribution: { points, violin }`, sparse: Outliers and no Violin are stored as nothing, so a box plot saved before R81, and one put back to the defaults, has no `distribution`. Anything unknown reads as the default.** Not flat `points`/`violin` keys, which other types (the Map's Points layer) may want. Lane CHARTS-B's call, overturnable. | Matches the Customize tab's sparse options (AC-219) and the section's name; AC-306's "Outliers draws as before R81" holds by construction. | No |
| T990-2 Outliers without Each point is (AC-591) | Design 23 sheet 11's "Unavailable" mock shows None chosen and Outliers greyed with no Each point is; AC-591 disables only All, Beeswarm and Violin. Which holds? | **AC-591: None and Outliers stay choosable without Each point is, and Outliers stays the default.** Lane CHARTS-B's call, overturnable. | A box plot without Each point is draws each row as an observation (T399) and has always drawn its outliers; the mock's greyed Outliers would change today's drawing, which AC-306 forbids. | Yes: from sheet 11's mock |
| T990-3 a saved choice while Each point is is emptied (AC-591) | A box plot saved with Beeswarm or Violin then has Each point is removed. What shows and what's drawn? | **The choice stays in the options; while Each point is is empty the box plot is drawn, and the controls show it, as Outliers with no Violin (`drawnDistribution`). Setting Each point is again brings the choice back.** Lane CHARTS-B's call, overturnable. | The disabled controls must show what is drawn; keeping the choice means emptying a well and refilling it loses nothing. | No |
| T990-4 the controls' form and place (AC-591) | Sheet 11 draws Points as a segmented control and Violin as a switch, among the wells. Where and how are they built? | **On the Customize tab, its own Distribution section after Whiskers, a box plot's alone: Points as radio buttons as Whiskers' are, Violin as the tab's switch-styled checkbox with "where values gather"; the reason once below them, each disabled control described by it (`aria-describedby`). The component lives at `editor/wells/boxplotDistribution.tsx`, as T990 names it, and `CustomizeTab` renders it (no new CSS).** Lane CHARTS-B's call, overturnable. | direction.md §7i "Where each surface lives": Points and Violin are on the Customize tab. Radios match the tab's existing Whiskers group, and wiring it there is what puts AC-591 on the real surface. | Yes: radios, not a segmented control |
