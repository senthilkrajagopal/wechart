# Designs for approval — UI review 2026-09-24

Seven static mockups that go with `../ui-review.md`. Each is a self-contained HTML file (inline CSS, direction.md tokens, Inter and IBM Plex Mono from Google Fonts, no other requests). Open one in a browser: a 1440 × 900 screen with numbered pins, then the notes explaining each pin, then the other states of the same screen at full size.

- Members and cubes are the sample model's (`orders`, `customers`, `products`, `order_summary`). The numbers are illustrative, so the charts have shape.
- Anything that would add a feature not in `docs/spec.md` is marked **proposal — needs the user's approval**, in the mockup and below.
- The prototype (`docs/design/prototype/`) is the reference throughout. Where a design goes beyond it, the notes say so.
