What changes, and why

Today, /explore/charts/seed-chart-status offers a primary "✎ Edit chart"; the editor it opens has no Save, only "This chart belongs to a dashboard; edit and save it there." — after the user may already have changed things (app-30, app-40). The details pane uses a raw select and a full-width Delete; a KPI chart shows its number at 14 px (app-31).

  1. 1
    The primary action goes where the chart can be savedFor a local chart: Edit on Company dashboard 01 opens that dashboard in edit mode with this tile's editor (the overlay, which saves the dashboard), and Save to folders… makes it a shared chart that can be edited here. For a shared chart the primary stays "✎ Edit chart". If the editor is ever reached for a local chart, it offers the same two buttons in place of the sentence.UX-040 (critical)
  2. 2
    Name the drawn form, and say who owns the chart"Bar, grouped · auto" rather than "Bar" over three series; beside it, "Local chart · only on Company dashboard 01" with the dashboard chip, as the editor header already words it.UX-065 · UX-040
  3. 3
    The tile as it is on a dashboardOne freshness badge and the row count in the head; values labelled at the bar ends because the chart has room for them here (six bars, direction §6's "selective" labels).UX-021
  4. 4
    "Lives on" for a local chart, "Used in" for a shared oneThe dashboard as an Explore item row that opens it, with one sentence on what local means. For a shared chart this section lists every dashboard and ends in "＋ Add to a dashboard…" (state B).UX-042
  5. 5
    Destructive and occasional actions in ⋯Delete chart… (with confirmation), Copy link, View query, Download CSV. Today "Delete chart" is a full-width button in its own section of the pane.UX-042

B · A shared library chart that is a KPI

The KPI uses text-kpi-solo (40/52/600, tabular figures) centred in the tile, with the label above in the tile-title style — today "240" is 14/400 body text with the label under it. The pane's "Used in" ends in the prototype's "＋ Add to a dashboard…", opening a searchable picker of dashboards instead of a label + native select + disabled button.
