What changes, and why

Today the drawer is a lone 73 × 32 px "Results" button; opened, it shows four identical bordered buttons and a browser-default table (14 px, 1 px padding, centred headers, left-aligned numbers). The analyst uses this drawer to check that the chart is right, so it has to be visible, legible and exact.

  1. 1
    Open by default, and resizable240 px when the editor opens (the prototype's 220 plus a row), dragged from 160 px to half the canvas (direction.md §2 "Bottom drawer"), double-click to reset. The preview keeps its tile and simply gets shorter.UX-058
  2. 2
    A real tab strip, always visibleThe prototype's .tabs: 36 px, 12/600, the selected tab in accent with a 2 px underline. Results shows its row count; Acceleration shows a hollow dot when no pre-aggregation serves the chart (✓ when one does). Collapsing leaves only this strip (state E), so the drawer is never hidden behind a button.UX-058 · UX-095
  3. 3
    What the answer is, and what to do with it"24 rows · 42 ms", then Copy (tab-separated, pastes into a spreadsheet), Download CSV, and collapse. Copy and Download CSV go beyond the prototype; the dashboard tile menu already downloads CSV.UX-058
  4. 4
    One data grid for every table in the product12 px, a sticky 28 px bg-subtle header with the role chip, 24 px rows with rules, a muted row number. The same grid serves the preview's Table view and the dashboard tile's Table view, which are browser-default tables today.UX-024
  5. 5
    Numbers read as numbersMeasures right-aligned in tabular figures and in the model's format (currency here); dimensions left-aligned; a colour dimension carries its series swatch, so a row can be found in the chart.UX-024 · checklist 1
  6. 6
    The rollup-only note lives with the badge it explainsHovering or focusing "Raw query" says what it means and links to Acceleration. It is shown as a banner only when Cube is known to run in rollup-only mode, where it is a real problem. The per-chart note the capability inventory asks for is kept; only its weight changes.UX-062
  7. 7
    The inspector is Design 01Shown here in Auto, where no Recommended card is needed and Auto is the pressed quick pick.UX-050 … UX-056

B · Underlying rows — records you can trace

Today this tab repeats the chart's own columns with a count of 1 per row, so no row leads to a record. Here the underlying query adds the measure's drill members when the model declares them (Cube returns drillMembers in /v1/meta, docs/research/cube/data-apis.md), and otherwise the cube's primary key and time dimension.

Proposal — needs the user's approval It changes the underlying query's members, which AC-036 describes as "the underlying rows … for the current chart".

The cap is said, as the app already does ("first 200"), and Download CSV exports the same capped query.

D · Acceleration — the answer to "why is this slow?"

The app's existing Acceleration tab, given the grid's typography and a clear next step. It states which pre-aggregation served the chart, or why none could, and where to add one. The rollup-only sentence sits here as information rather than as a warning on every chart.
