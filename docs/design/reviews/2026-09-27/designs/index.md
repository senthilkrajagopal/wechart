# Designs for approval — UI review 2026-09-27 (phase 2)

Ten static mockups that go with `../ui-review.md`.

- **Format:** each is a self-contained HTML file (inline CSS in direction.md's tokens, Inter and IBM Plex Mono from Google Fonts, no other requests). Open one in a browser: a 1440 × 900 screen with numbered pins, then the notes explaining each pin, then the other states.
- **Where they come from:** phase 2 has no prototype screens, so these follow `docs/design/references.md` › Phase 2 › Surfaces 1–10, direction.md §7e and rules 59–89, and the acceptance criteria they cite. The approved prototype's visual language is used throughout: tokens, `.pane`, `.tabs`, `.badge`, `.seg`, `.switch`, `.grid-table`.
- **Illustrative content:** people, folders, groups, versions and numbers are illustrative. Driver fields and defaults are `packages/core/src/data-sources/drivers.ts`'s. The failed test in Design 01 is the review's real run.
- **Proposals:** anything that would add something not in `docs/spec.md` is marked **proposal — needs the user's approval**, in the mockup and below.
