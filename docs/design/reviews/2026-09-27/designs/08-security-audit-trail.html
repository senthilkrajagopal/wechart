What changes, and why

Security becomes three tabs. Policies and the preview are phase 1's, reworded for groups. The audit trail is new, and is the only page in wechart that spans every folder. It is shown to Super-Admins only; for anyone else the switcher has no Security, and a direct link renders Not found (AC-001, AC-295, rule 67).

E · Preview as groups (AC-166 as amended)

Choose one or more AD groups (the same "AD group" combobox as the Access panel), then a dashboard. Its queries run as a token carrying exactly those groups. A persistent banner names them while the preview is on (rule 21). The effective access includes the folder check xcube makes (AC-320), so the preview answers "which folders do these groups reach?" as well as "which policies apply?". This replaces today's JSON editor and "Find a dashboard".
