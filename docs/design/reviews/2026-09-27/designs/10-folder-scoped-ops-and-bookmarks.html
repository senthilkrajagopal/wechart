D · The cube picker, by folder path (AC-329)

In the chart editor's source picker, only cubes found on the item's folder path: its own folder, then each folder above to the root. For a workspace item, the workspace comes first, then its origin's or target's path. Each is listed by its title, with its folder path beside it and never a prefixed name. A cube in a sibling or descendant folder isn't offered. When two folders on the path define the same name, only the nearest can be chosen, because that's the one it binds to at publish (AC-272, AC-281). The farther one is listed dimmed, "hidden by" the nearer, so its absence isn't a mystery. Drawn for a workspace chart copied from Sales / EMEA.
