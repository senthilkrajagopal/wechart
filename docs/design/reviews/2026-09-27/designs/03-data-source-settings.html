Task T461 has no screen yet. Today a data source's row in Explore has a pointer cursor and opens nothing, and in Data sources it doesn't open either (UX-222). This page opens under the item's folder breadcrumb. It has the tabs surface 4 names (General, Connection, Test history, Usage) and a fifth, In Cube, for AC-161's per-instance state. The type is fixed, with the way to use another (AC-161). Secrets read "Stored · encrypted" or "Kept from folder · encrypted" (AC-164, AC-280, rule 83).

The edit rule is yours: a change to the connection is saved only once a test of exactly that change passes. There is no override. A rename alone needs no test (AC-158, T461). Changing a field the secret is bound to clears the secret and asks for it again (AC-312). The main screen shows a workspace copy with its host changed.
