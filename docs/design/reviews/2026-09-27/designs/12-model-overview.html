Model overview — one table of every cube and view, beside design 03's tree

With no file open, /model shows one card per file (critique MW-01). Each card has an underlined 13/600 mono path, an uppercase "CUBE" tag, and member names as 13 px running text. Five cards fill the 852 px pane, so the views sit below the fold. The 720 px InfoBar doesn't line up with the 960 px cards, and the title row has no action. The tree beside it has a 97 px "Files" head with three bordered buttons wrapping onto two rows, folder labels 16 px tall with no ▾, inset pill rows, and no Jinja tag (MW-02, MW-03). The re-check asked for "the overview as a table of files" (UX-079, item 57).

This design draws the overview as one card with a grid table, one row per cube or view, as MW-01 recommends. It sits beside design 03's tree, with the head, rows and foot MW-02 and MW-03 recommend. Everything the cards list today is still there: each file, what it defines, its members, whether it can be read, and whether it's a Jinja template (AC-131). It adds the unpublished mark the tree already shows.
