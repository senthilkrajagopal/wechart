What changes, and why

Each driver's form asks only what that driver takes, in the same three groups. A choice that decides which fields apply comes first, as cards that say what each option means. Nothing here adds a field or a method: they are drivers.ts's, which AC-160 ticks against xcube.

    Dremio Cloud or Dremio Software, asked firstTwo cards, each saying what it takes. xcube needs a URL or a host, and a URL takes only a token (research, xcube-slice-6.md). Today the Cloud URL, the Software host, port and HTTPS switch all show at once. The Password method's "Dremio Software only" note appears only after it's chosen.UX-206 · AC-160

What changing a field does to a stored secret

Not visible in the wizard, where nothing is stored yet. In a stored data source's settings (Design 03), a change to a target field clears its secret and asks for it again (AC-312). The target fields are: host, port and the TLS fields (PostgreSQL, Redshift, MySQL); server, port, encrypt and trust (SQL Server); account, region and warehouse (Snowflake); project (BigQuery); connect string, host, port and service name (Oracle); URL, host, port and HTTPS (Dremio). Design 03 marks them with a lock-and-link icon beside the label.
