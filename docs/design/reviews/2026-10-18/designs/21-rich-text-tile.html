Screen 1: editing in place, and why

Spotfire's text area could only be authored in the installed client, with free fonts, raw HTML and scripts. wechart's Text tile is authored where it's read, on the canvas, with typed blocks on §3's scale and elements that are references, never HTML. The Markdown tile becomes this tile; nothing a reader sees today changes until an author adds something.

  1. 1
    Edited on the canvasIn edit mode, double-click a Text tile, or "Edit text on the canvas" in Properties, and its text becomes editable in place: a 2 px accent border, the toolbar on top. Esc or a click outside leaves the text; the tile stays selected. The dashboard's Undo takes the whole edit as one change when the text is left.AC-302 (amended) · rule 128 (new) · Hex text cells
  2. 2
    Block style, from §3's scale onlyParagraph (text-sm), Heading small, medium and large (text-md, text-lg, text-xl), and Large value (text-kpi 32/40, for a lone Value or Change). No free colour, font or size, so the 12 px floor and the contrast audit hold (state A).rules 1, 2 · rule 128 (new) · Spotfire B7.9
  3. 3
    Bold, italic, lists, linkThe markdown subset AC-208 renders today. A link takes a dashboard or an http(s) address, as the Link/button tile does; anything else is refused with its reason. Markdown shortcuts work as typed: #, -, 1., **…**, *…* (state A).AC-208 · rule 42 · Tiptap StarterKit
  4. 4
    InsertOpens the same menu as / and {{ (pin 6), at the cursor. It's a menu button, so it's reachable from the toolbar by keyboard.rule 129 (new)
  5. 5
    "8 / 10 elements"Every element counts: live values, controls and buttons (Q4). At 10, Insert and the menu's rows are disabled with the reason (state E). Elements sharing filters and granularity are batched into one Cube query.R80 "10 elements" · rule 131 (new)
  6. 6
    The insert menuOpened by / at a line's start or after a space, by Insert, or by {{ (today's token syntax). A combobox and listbox, 320 px wide, 28 px rows (APG): ↑ ↓, Enter, Esc. Kinds first in three groups, Live values, Controls and Copilot; typing narrows them and adds measures from this dashboard's cubes, grouped by cube (state B).rule 129 (new) · W3C APG combobox · Notion, Hex
  7. 7
    A live element, in edit modeAn atom: the cursor steps over it as one character; Backspace removes it whole. Drawn on bg-subtle with a 1 px border-subtle outline, radius 4, at the text's own size. Selecting one (click, or arrow onto it) opens its settings in Properties (pin 13).rule 130 (new) · research §1 inline atom node
  8. 8
    Change, Icon: state with a shapeChange shows ▲ or ▼ and its sign, coloured by its direction setting. Icon always pairs an icon with its label ("On track"); an icon with no matching rule shows the neutral ○ and "No rule matched", never nothing (Spotfire's blank icon fixed).rule 3 · rule 133 (new) · Spotfire B3, B7.6
  9. 9
    Sparkline and bullet graph, word-sizedwechart's own SVG in the line: a 64 × 16 sparkline, a 2 px line in the measure's dashboard colour, no axes or markers; a 96 × 16 bullet graph, its value bar in text-primary, its target a 2 px rule, its ranges in three greys from §5 (bg-subtle, border-subtle, border-strong).R80 "wechart's own SVG" · research §3 option D · rule 133 (new)
  10. 10
    Filter value and As ofFilter value prints what a dashboard filter is set to ("Germany, France"; "all countries" when unset). As of prints the data's age ("as of 14:05"), and its tooltip says whether a pre-aggregation answered (rule 19).rule 19 · rule 130 (new)
  11. 11
    The insert menu's three groupsLive values (8 kinds), Controls (filter control, parameter control, action button) and Copilot (Summarize…). Copilot is listed only when a Super-Admin has turned AI on and this author may use it (state J).R80 · rule 138 (new)
  12. 12
    The keyboard route inA focused Text tile's Enter focuses its Properties, as for every tile (§7); "Edit text on the canvas" is Properties' first control and moves focus into the text. No new key (Q11).§7 Keyboard · AC-176 · rule 146 (new)
  13. 13
    Elements, listedEvery element in text order with its kind and its source, "8 of 10". Choosing a row selects that element in the text and opens its settings below, here Value · Margin %: the measure, format (the model's, AC-046), Limit by marking, and its own filter, added to the tile's.state C · AC-116 (extended)
  14. 14
    InteractionsMarkings mode: an element follows a marking only when it names one (AC-116). Cross-filter mode: the tile is a target like any tile, Filter or None; Highlight is shown disabled, "Text has no marks to highlight" (state H).AC-116 · rule 32 · rule 130 (new)

Screen 2: what a reader sees and does

A reader reads sentences, not chips. Every number is current for the filters and marking that reach the tile, and says where it came from when asked. The Controls tile is Spotfire's text area with property controls, filters and action buttons, built from declarations, not scripts.

  1. 1
    Values read as textIn the sentence's own type and weight, tabular, in the member's model format (AC-046), with no chip. The Large value line is text-kpi. A value is focusable; on hover or focus it takes a dotted underline in text-muted and shows its tooltip (Q2).rule 132 (new)
  2. 2
    The tooltip: what this number isThe element's kind and measure, what it compares, the filters in effect (the tile's and its own), the marking it follows, and the data's age with whether a pre-aggregation answered. The same text is the value's accessible description.rule 132 (new) · rule 19 · Power BI dynamic values
  3. 3
    Sparkline and bullet graph, describedEach is an image with a text alternative: the sparkline names the measure, the period, first and last values, low and high; the bullet graph names the value, the target and the ranges.rule 133 (new)
  4. 4
    Change and Icon keep their shape"▲ 4.2%" in status-success because Revenue's direction is "Higher is better"; "On track" with its icon. The same states read without colour: the triangle, the sign and the word.rule 3 · rule 133 (new)
  5. 5
    A parameter control"Show" switches the dashboard parameter Metric to show among Revenue, Orders and Margin % (screen 3). A segmented control with up to 5 choices, a list beyond. Its change applies at once, is said once politely ("Metric to show: Orders"), and goes into bookmarks and "Copy link" (AC-121 amended).R80 "field switch now" · rule 137 (new) · Spotfire B4
  6. 6
    Filter controls are the filter bar's filtersNot copies: the same filter, scope tag, value and popover as the bar (AC-077). Changing Country here changes the bar's pill and the header's count, and the reverse. A filter can sit in several Text tiles; there is still one filter.rule 135 (new) · rule 14 · Spotfire B6
  7. 7
    A chart that follows a parameter says so"· set by Metric to show" beside its title, in view mode, so a reader knows what changed the chart. Its title, axis and format follow the chosen measure; its chart type stays as its author pinned it.rule 137 (new) · principle 2
  8. 8
    Action buttonsThe Link/button tile's styles (Button, Primary, Text link), each running an ordered list of declared actions: go to a page tab, apply a bookmark, reset filters, export (state E). No script runs; nothing happens that a bookmark or a link couldn't record.R80 · rule 136 (new) · Spotfire B5
  9. 9
    The compact header agrees"Filters 3": the same three filters the Controls tile shows two of. A change made in the tile highlights the count for 2 s, as any filter change while collapsed (design 19 B).AC-493 · rule 113
  10. 10
    Prose beside controlsA Text tile can hold only controls, only prose, or both. Its headings stay in the tile's outline (h3…h6), so a screen reader's heading list includes them.AC-208 · rule 127 (new)

Screen 3: defining a dashboard parameter

Spotfire's document property, as a column name on an axis, is the classic "pick the measure from a drop-down". wechart's version is a typed object on the dashboard, not a string substituted into an expression, so a bookmark, a link and a chart can each name it.

    Parameters, a settings sectionAfter Cross-filtering, before Layout, with the count.   2. 2
    New parameterAlso offered from the insert menu's "Parameter control" (state F) and from a chart well's picker, both of which open this form in a 520 px dialog and return to where they came from.rule 137 (new)
  3. 3

  5. 5
    Choices, ordered, with labelsMembers from the dashboard's cubes, picked with the field picker (never typed), each with the label its control shows. Drag or the ⋮⋮ menu (Move up, Move down) orders them. Up to 1,000, Spotfire's and Power BI's cap; R80's 1,000 values.R80 "1,000 values" · rule 11

Screen 4: an AI summary, facts first, reviewed before it lands

R80: "facts computed through Cube, every number a live value, review by the author, and no silent regeneration". Copilot writes only the words; wechart computes every fact first, as Tableau Pulse computes its "ground truths" before AI writes them up.
