# Lane CLOSE's design decisions

Lane CLOSE's calls, made while closing ACs that no open task covered. They are kept apart so lanes don't conflict. The earlier ones, and everyone else's, are in [decisions-2026-10-08.md](./decisions-2026-10-08.md) under "Later decisions".

| ID | Question | Decision | Why | Departs |
|---|---|---|---|---|
| CLOSE-1 Cube Store's own page and a `{{ name }}` (AC-482) | Cube Store's page (`/explore/data-sources/cubestore`) still has an editor of its own (T823 kept it). Should it hold Run for SQL with a `{{ name }}`, the way the SQL runner workspace does? Before this call, Run there sent the SQL, and the API refused it with the reason. | **Hold it there too.** Run is disabled, and the run bar says "Parameters aren’t available on Cube Store. Write the value into the SQL to run it here." (T810's sentence). ⌘/Ctrl+Enter is held too. A `{{…}}` inside a string or a comment isn't a parameter, so that SQL runs as written. The parameter is found as the API finds it: `parameterNames`, read as standard SQL. Lane CLOSE's call, overturnable. | AC-482 says Cube Store "SHALL hold Run, saying parameters aren't available". It doesn't limit this to the workspace. | No |
| CLOSE-2 the compact chips from 1,024 to 1,279 px (AC-484, AC-200, AC-119, AC-494) | A compact chip is up to about 240 px wide. With one in the row at 1,024 px, the row ran about 42 px past its room: the page tabs shrank to nothing, and the Filters toggle ran off the window's edge. What gives way? | **The coordinator's call, (a): below 1,280 px the compact chips collapse to a count.** It reads "n filters" ("1 filter") for cross-filters and "n markings" ("1 marking") for markings. It is a 24 px pill, a button in the chips' place, so the row order is unchanged. Its accessible name and tooltip list what it holds, each as its chip names it: "2 filters: Status = shipped, from By status; …". It opens the header sheet, where the full chips are, and focus goes to the Filters toggle, as the toggle's own press leaves it. The chips and "+n" are still drawn and hidden by the stylesheet, as History's and Bookmarks' words are (AC-494). From 1,280 px nothing changes. Below 1,024 px no chip shows (AC-495). | Design 19 gives no rule for when a compact chip and the actions don't fit at 1,024–1,279 px. The count keeps what's set in the row, as AC-200 and AC-119 ask, in a fraction of the room. | Departs from design 19 D1, which draws the chips at every width from 1,024 px |
