A token keeps the emphasis around it and its place, and is never inside a link: a link's words either side of it stay linked. | T870-1 the markdown form of a Text document (AC-527) | Which token names each element, what has no markdown form, and how does typed text survive? | **Value and Marking keep the markdown tile's tokens (`{{measure:m}}`, `{{measure:m \| marking:‹name›}}`, `{{marking:‹name›.count}}`/`.summary`).
