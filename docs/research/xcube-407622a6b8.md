## The field

`GET /v1/semantic/models/{model}/revision` answers `rollupOnly: boolean | null` at its top level, beside `current` and `instance` ([answer]). In [commit], the runtime's status adds `rollupOnly: await this.rollupOnly(model)`. `GET …/refresh-worker` carries the same field beside `revision` (`routes.ts` L604).

- **`true`:** the answering instance answers this model's queries in rollup-only mode.
- **`false`:** it doesn't.
- **`null`:** only where no Cube is attached to xcube ([answer]; [commit], `rollupOnly()` returns null without `core.rollupOnlyFor`).
- **How it is worked out:** as Cube resolves it for the model's context. That is `orchestratorOptions.rollupOnlyMode` where the deployment's `cube.js` sets it, else `CUBEJS_ROLLUP_ONLY` ([commit], `rollupOnlyFor`: `given.rollupOnlyMode !== undefined ? Boolean(given.rollupOnlyMode) : Boolean(getEnv('rollupOnlyMode'))`). The environment is read when asked ([answer]).
- **It is the answering instance's:** an API instance and the refresh worker can differ, so read it from the API instances, as `/revision` does ([answer]).
- **Tested by xcube** (`test/integration/items.test.ts`): both routes answer `false` without `CUBEJS_ROLLUP_ONLY`, `true` with it, and `false` again once it is unset ([answer]).

## How wechart uses it

- `XcubeAdmin.revision()` passes `rollupOnly` on where it is a boolean. It leaves it out for `null`, and for an image before 407622a6b8, which has no such field.
- `GET /api/rollup-only` answers `{ rollupOnly: true | false | null }`. It is null without xcube, or where xcube doesn't answer.
- The chart editor shows AC-147's banner on `true`. While wechart can't know (`null`), it falls back to inferring the mode from Cube's refusal text (`cube/rollup-only-mode.md`).

## Gotchas

- The answer is per model and per answering instance. With several API replicas, a deployment that sets the mode on only some of them gives different answers. wechart reads it once per editor session, from whichever instance answers.
- The compose stack must run this image for `rollupOnly` to appear. An older image answers no field, and wechart reads that as "can't know".
